# 📊 Sistema Avaliador de Funcionários

Projeto prático desenvolvido para exercitar os primeiros conceitos de **JavaScript** e manipulação do DOM no curso Técnico em Desenvolvimento de Sistemas do **SENAI Gama**.

---

## 💻 Sobre o Projeto

Este é um exercício básico de fixação com o objetivo de capturar dados informados pelo usuário via formulário HTML, processar regras de negócio utilizando estruturas condicionais no JavaScript e exibir o resultado dinamicamente na tela.

### 📋 Regras de Negócio e Funcionalidades

1. **Entrada de Dados:**
   - Nome do Funcionário
   - Anos de Experiência
   - Salário

2. **Classificação por Senioridade:**
   - **Menos de 2 anos:** Júnior
   - **De 2 até 5 anos:** Pleno
   - **Acima de 5 anos:** Sênior

3. **Verificação de Bônus:**
   - **Salário > R$ 2.500,00:** Elegível para bônus de **R$ 300,00**
   - **Salário ≤ R$ 2.500,00:** Sem bônus

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação dos elementos da página (formulário, rótulos e botões).
- **CSS3:** Estilização básica da interface.
- **JavaScript:** Manipulação do DOM, funções e lógica condicional (`if / else`).
